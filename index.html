Usage Dump

Usage Dump is a small Android app that records how you use your own phone (screen time per app and per hour, unlocks, notifications, and pick-ups) and shows it as a dashboard. It is a personal project, shared with friends; it is not sold and carries no ads.

How it works

Every 6 hours the app reads the phone's own usage statistics (the same data Android's Digital Wellbeing uses, with the Usage access permission you grant) and saves them as files on the phone. If you connect Google Drive, it uploads those files to a folder named PhoneUsage in your Google Drive, where an optional dashboard on your own computer can read them.

Google Drive access

The app asks Google for one permission: drive.file, which only lets it see and change the files it creates itself. It cannot list, read or delete any other file in your Drive.
